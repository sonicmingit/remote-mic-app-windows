# Windows 剪贴板听写验收

## 自动浮窗投送测试版（2026-11-05 追加）

连接 → 豆包输入法 → 开启“浮窗听写后自动粘贴（测试）”。重启后需重新开启。
本节测试新开关；下方原手动听写入口保留。

1. 在目标软件的输入框放好光标与选区，按住遥控器语音键说一句，松开后等豆包完成提交。
   核对浮窗接到完整首尾、系统剪贴板为本轮全文、浮窗关闭、焦点回到原输入框，并只插入一次。
   在原选区中替换文本、光标处插入以及多行/表情分别核对，不只看日志的 accepted。
2. 冷态/真实闲置后首用、连续会话、快速按下释放、空识别分别执行。下一轮不得携带上一轮文字；
   旧输入法回调、重复 IME_END、断连或睡眠后的迟到结果不能再次 Ctrl+V。
3. 按住期间主动切走窗口、识别期间关闭原目标、原输入框失效：停止自动投送，浮窗保留文字，
   用“复制全部”手动恢复。不搜索其他输入框或向新的前台窗口发键。
4. 剪贴板被占用时接字窗口保持可见，释放占用后仅投送一次；等待超时保留文字。复制后有新的
   剪贴板更改则不投送；Ctrl+V 被拒绝或只接受部分边沿也不得自动重放。原快捷键 UP 严格配对。
5. 关闭开关、切换输入工具、断连、睡眠、退出、重复取消后，无浮窗/待投送会话残留；
   新会话仍可用。按住修饰键时不得混入 Ctrl+V，释放修饰键后才能投送。
6. 诊断 `clipboard_probe` 的 copy / hide / restore / paste / delivery 分别记录；copy=passed
   来自自写 Unicode 数据读回，restore=passed 来自前台与焦点读回；paste=accepted 只表示输入已提交，
   不表示目标软件实际插入文字。日志不得含正文、窗口标题、设备身份或个人路径。

RC001 与 RC003 分别记录以上用例；用户目前只确认浮窗与接字，型号及完整自动投送仍为 deferred。

无可见窗口的系统剪贴板测试（会用合成字符串替换剪贴板，不读取旧内容或发送全局键）：

```powershell
cargo test -p sayall-windows --lib clipboard_probe::native::delivery::tests::native_unicode_clipboard_readback_and_hidden_edit_paste --locked -- --ignored --exact
```

该测试把合成 Unicode 文本复制后向自有隐藏 EDIT 发送 WM_PASTE，并逐字读回；
不是豆包/遥控器/第三方应用 Ctrl+V 的验收替代。

## 自动化

`pnpm test`、`pnpm build`。新增宿主 capability 需在具备完整工具链时执行
`scripts/ci-preflight.ps1` 与 `scripts/build-local-test-package.ps1`。

## 本地安装与真实豆包

安装前正常退出正在连接的 SayAll，不强杀。验证升级保留设置、安装版启动，豆包入口可见。
RC001 和 RC003 各自记录 passed / failed / deferred，不互相替代：

1. 在豆包面板打开听写窗口。初始为空，焦点在输入框；选中豆包为当前 Windows 输入法。
2. 冷态/真实闲置后首次按住语音键说话，松开后等识别完成。将结果粘贴到独立记事本，
   与窗口内容逐字比对；不能只看“已复制”状态或 Clipboard API 返回值。
3. 连续说两段，包含标点、换行和中英文；粘贴结果包含窗口全部文字，不只包含最后一段。
   较长一段确认输入中的临时组合文字不触发复制，最终整理结果仍自动更新剪贴板。
4. 在不能直接接收豆包文字的目标软件重复步骤 1–3，通过手动粘贴确认可接收结果。
5. 点“清空内容”后在记事本粘贴，剪贴板仍是上一段；再说新内容只包含新文字。
6. 模拟剪贴板被占用/拒绝写入：窗口保留文字并提示失败，恢复后“复制全部”可重试。
7. 点击入口两次、最小化后再打开：只有一个窗口，原文字仍在，输入焦点可用。
   关闭后重开：文字为空，剪贴板保留。关闭/切走时没有排队复制覆盖用户后来复制的内容。
8. 断连、取消、睡眠恢复、快速按下/释放与退出：原语音生命周期与基础输入不回归，
   回来后新会话可用。记录冷态和热态结果，不能只测热态。
9. 简体中文/英文、浅色/深色与小窗口宽度核对；普通直接输入路径仍可用。
10. 诊断只包含 `clipboard_dictation_open` / `clipboard_dictation_copy` 的阶段、结果、
    短操作标记和耗时；无听写正文、设备身份或个人路径。确认没有新建文字历史文件。

受控自动化已覆盖慢剪贴板写入、迟到回调和宿主创建超时；真实剪贴板被占用场景应另行记录。
原生 Clipboard API 已提交的写入没有取消接口，不能声称关闭窗口能撤销已提交的系统操作。
